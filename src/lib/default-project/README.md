New projects use the canonical `static/brand/griffpatch-studio.svg` costume, centred at (32, 32) and displayed at 100% (64 × 64 stage pixels). Existing projects are not changed.

The retained legacy `dango-cat.svg` was created by https://scratch.mit.edu/users/littlebunny06/ 🍡🐱 and is no longer used as the default costume.

If `default-project.sb3` is replaced with a non-empty file, it will be used instead of the costumes.

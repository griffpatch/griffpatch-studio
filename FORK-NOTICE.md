# Griffpatch Studio fork notice

Griffpatch Studio is a modified TurboWarp GUI, based in turn on Scratch GUI.
Local modifications began in August 2026 and include keyboard block authoring,
navigation and completion, Finder integration, workspace minimap and script
context UI, layout behaviour, and Griffpatch Studio identity. Git history records
the individual changes. Some experimental Studio features remain in the source.
